# 💬 Chatterbox

A basic WhatsApp-like chat application built using **FastAPI** and **WebSocket** for real-time communication. The app supports sending, editing, and deleting messages — all in real-time!

---

## 🚀 Features

- Real-time messaging with **WebSocket**
- **Send**, **Edit**, and **Delete** messages (basic CRUD)
- Minimal, clean **frontend** with vanilla HTML, CSS, and JavaScript
- **FastAPI** backend for handling WebSocket connections
- In-memory message storage for quick prototyping

---

## 🛠️ Tech Stack

- **Backend**: FastAPI, Python
- **Frontend**: HTML, JavaScript, CSS
- **WebSocket**: Native WebSocket API
- **Server Deployment**: Uvicorn
